## Introduction

In this course, you will learn about the fundamentals of GitLab CI/CD, how to set up and configure pipelines, write and manage YAML files, and deploy applications to AWS. This course is structured to build your knowledge step-by-step, providing hands-on examples and exercises along the way.

## Prerequisites

- Basic knowledge of Git
- Familiarity with software development concepts
- An active GitLab account
- (For the final module) An AWS account with permissions to deploy applications to Elastic Beanstalk

## Sub-directories Overview

### [GitLab CI Introduction](01-gitlab-ci-introduction/README.md)

This module provides an overview of GitLab CI/CD, explaining the key concepts, features, and benefits. You'll learn about the basics of continuous integration and continuous deployment, and how GitLab facilitates these processes.

### [Basic CI/CD Workflow](02-gitlab-ci-basic-cicd-workflow/README.md)

In this module, you'll learn how to set up a basic CI/CD workflow in GitLab. The focus will be on creating a simple pipeline that runs tests and builds your project. You'll understand the structure of a `.gitlab-ci.yml` file and how to define jobs and stages.

### [GitLab CI Fundamentals](03-gitlab-ci-fundamentals/README.md)

Building on the previous module, this module dives deeper into the fundamental concepts of GitLab CI/CD. You'll explore advanced job configurations, using variables, caching dependencies, and setting up manual jobs and pipelines.

### [YAML Basics](04-yaml-basics/README.md)

YAML (YAML Ain't Markup Language) is the format used for writing GitLab CI configuration files. This module covers the basics of YAML syntax and structure, ensuring you have a solid understanding to write and maintain your CI/CD pipelines.

### [Building and Deploying Java App to AWS Beanstalk](05-building-and-deploying-java-app-to-aws-beanstalk/README.md)

The final module guides you through a real-world example of building and deploying a Java application to AWS Elastic Beanstalk using GitLab CI/CD. You'll learn how to configure your pipeline for deployment, manage secrets, and integrate with AWS services.
