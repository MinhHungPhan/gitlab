# Caching in GitLab CI/CD

Welcome to the "Caching in GitLab CI/CD" course! This course is designed to help you understand and leverage caching in GitLab CI/CD to optimize build speeds and improve pipeline efficiency. Through this course, you'll learn the best practices for implementing and managing caches in your CI/CD pipelines.

## Introduction

The "Caching in GitLab CI/CD" course covers the fundamentals of caching in GitLab CI/CD. You'll learn how to use caches effectively to speed up your build processes, understand the difference between caches and artifacts, and optimize cache performance in your pipelines. By the end of this course, you will be able to implement caching strategies that reduce redundant work and save time in your CI/CD workflows.

## Prerequisites

Before starting this course, ensure you have the following:

- Basic understanding of GitLab CI/CD pipelines
- Familiarity with writing and editing `.gitlab-ci.yml` files
- Access to a GitLab project with CI/CD enabled
- Basic knowledge of CI/CD concepts and terminology

## Sub-directories Overview

### [Using Caches to Optimize the Build Speed](01-using-caches-to-optimize-the-build-speed/README.md)

In this module, you will learn how to use caching in GitLab CI/CD to optimize build speed. The module covers how to configure cache paths in your `.gitlab-ci.yml` file, the types of data that can be cached, and how to ensure that your caches are effectively utilized across multiple jobs and pipeline runs.

### [Optimizing Cache Performance in GitLab](02-optimizing-cache-performance-in-gitlab/README.md)

This module dives deeper into optimizing cache performance. You will explore strategies to maximize cache efficiency, minimize cache size, and manage cache expiration. The module also covers common pitfalls and how to avoid them to ensure your caches are always up-to-date and performant.
