# Merge Requests in GitLab CI/CD

Welcome to the "Merge Requests in GitLab CI/CD" course! This course is designed to help you understand the power of merge requests (MRs) in GitLab CI/CD, focusing on how to improve your Git workflow with branches, configure GitLab for MRs, and effectively manage merge requests to ensure smooth collaboration and efficient code review processes.

## Introduction

The "Merge Requests in GitLab CI/CD" course covers the essential aspects of working with merge requests, from improving Git workflows using branches to setting up GitLab for merge requests. You'll also create your first merge request and learn best practices for managing MRs effectively in a collaborative environment.

By the end of this course, you'll have a deep understanding of how to use merge requests to enhance team collaboration, manage code changes, and improve the quality of your software development process.

## Prerequisites

Before starting this course, you should have the following:

- A basic understanding of Git and version control
- Familiarity with GitLab and GitLab CI/CD concepts
- Experience with creating and working with Git branches
- Access to a GitLab project with permission to create merge requests

## Sub-directories Overview

### [Improving Git Workflow with Branches](01-improving-git-workflow-with-branches/README.md)

This module introduces Git branching strategies and explains how branches can be used to improve your development workflow. You'll learn about common branching models like Git Flow, and how to structure branches to facilitate clear, isolated development work and smoother integrations.

### [Merge Requests: Configuring GitLab](02-merge-requests-configuring-gitlab/README.md)

In this module, you'll learn how to configure GitLab to work seamlessly with merge requests. This includes setting up project rules, enabling MR approval settings, and configuring CI pipelines to automatically trigger builds and tests when a merge request is opened.

### [Your First Merge Request](03-your-first-merge-request/README.md)

Here, you'll go step-by-step through the process of creating your first merge request. This module covers everything from creating a branch and making changes to opening a merge request, assigning reviewers, and merging your code after a successful review.

### [Working with Merge Requests](04-working-with-merge-requests/README.md)

This module focuses on best practices for managing merge requests. You'll learn how to review code efficiently, leave constructive feedback, handle merge conflicts, and ensure that code is adequately tested and approved before it is merged into the main branch.
